# Anjolla Nails

Website za **Anjolla Nails** — nail studio na Čukarici, Beograd (Instagram [@anjolla_nails](https://www.instagram.com/anjolla_nails/)).

Jednostrani sajt: gel lak, ojačavanje i nail art. Zakazivanje putem Instagram DM-a.

## Sadržaj
- `index.html` — kompletan sajt (samostalan, bez build koraka)
- `images/` — fotografije koje sajt koristi
- `research/` — analiza referentnog dizajna

## Pokretanje
Otvori `index.html` u browseru, ili posluži folder statički:

```bash
npx serve .
```

## Tehnologije
Čist HTML/CSS + malo JavaScript-a (IntersectionObserver za animacije). Fontovi: Cormorant Garamond + Manrope (Google Fonts).
